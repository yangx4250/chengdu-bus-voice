# 西昌（月城公交）实时协议

从 月城公交 App 2.7.5 (`com.pandabus.android.yuecheng`) 的 TCP 流量逆出。
来源：root 手机 + 系统级 CA + iptables 把 `39.108.28.78:1787` 重定向到本地 TCP 代理。

## 为什么抓不到

实时数据**不走 HTTP**，是 `39.108.28.78:1787` 上的裸 TCP 明文协议。
ProxyPin / Charles 只能看到 App 启动时那几个 `:8800` 的 REST 请求，看不到车辆数据。

## 帧格式

```
偏移 0  magic    4 字节   00 00 BA BE
偏移 4  length   4 字节   大端，载荷长度
偏移 8  seq      4 字节   大端，请求/响应配对用
偏移 12 payload  length 字节，UTF-8 明文
```

握手：发 `magic + len=0 + seq=0`，服务器回同样 12 字节。

## 通用请求外壳

```
1;<毫秒时间戳>;xc;<userId>,<terminalKey>;...
```

`userId` / `terminalKey` 服务器**不校验**，随机 UUID 即可。不需要 sign。

## 请求类型

| seq | 请求载荷 | 返回 | 用途 |
|---|---|---|---|
| 2 | `1;ts;xc;uid,tk;lat,lng;lat;lng;0` | 附近站点+车辆（约 11KB） | 首页附近 |
| 7 / 31 | `1;ts;xc;;;<routeDirId>` | **线路站表** | 站名/坐标/站序 |
| 95 | `1;ts;xc;;;<routeDirId>;<dist>;<stationOrder>;<lat>;<lng>` | **车辆位置+速度** | ETA |
| 96 | `1;ts;xc;;;<routeDirId>;<dist>;<order>` | **站间距** | 分段耗时 |
| 97 | `1;ts;xc;;;<id>,<dist>,<order>,<lat>,<lng>:...` | 批量状态 | 状态码 |

`<routeDirId>` 就是附近接口里每条记录的第 2 个字段（如 184 / 185 = 107路 两个方向）。

## seq=7 站表

```
184:107路:0::0630:2100:20183:分段计费全程４元...:1;
1,2957,西宁,27.961355,102.193036:
2,2958,火车北站,27.956791,102.195622:
...
```

头部：`routeDirId:线路名:?:?:首班:末班:全程米数:票价:环线标记;<站数>;`
余下每段：`站序,站ID,站名,纬度,经度`，用 `:` 分隔。

## seq=95 车辆位置（含速率）

```
184:107路下行(西宁-川兴车站):川W00096D:川W00096D:27.901774:102.217447:40.0:8350:攀钢西昌医院路口:13:1617130:ts:ts:186:1;
```

| 位置 | 含义 |
|---|---|
| 0 | routeDirId |
| 1 | 线路名（含方向） |
| 2/3 | 车牌 |
| 4/5 | 车辆纬度/经度 |
| **6** | **速率（km/h）** ← 就是这个 |
| 7 | 距下一站（米） |
| 8 | 下一站名 |
| **9** | **车辆当前站序** |
| 10 | 车辆实时 ID |

## seq=96 站间距

```
1:12;2:34;3:41;4:21;...
```

`站序:数值`。**这个数值不是米**——拿站表坐标实算同一段距离，
比值在 0.02~0.12 之间浮动，单位未确定，因此不用于计算。

## 距离和 ETA 怎么算（已验证）

不要用协议里的数字字段当距离，全部改用**站表坐标现算**（Haversine）：

- 站表 43 站坐标累加 = 20160 米，协议头声明全程 20183 米，**相差 0.1%**，坐标可信。
- 剩余距离 = 车当前位置 → 下一站，再逐段累加到目标站。
- ETA = 剩余距离 ÷ 速率（seq=95 字段 6，km/h）。
- 车速 < 5km/h（停站）、已过站、已到站、剩余 <100 米：都不给 ETA。

## 已修正的错误

早期版本把字段 4 和 seq=95 字段 7 当成米数，界面上会出现
「距本站约 2991 米」这种假数据。现在这两个字段按站点 ID 解析，
距离改由坐标计算。

## 算「还有几站 / 还有几分钟」

- 还有几站 = `目标站站序(字段5) - 车辆当前站序(seq=95 第9位)`
- 还有几分钟 = 剩余距离 ÷ 速率。剩余距离可用 seq=96 累加，或直接用 seq=95 的「距下一站」逐段推。
